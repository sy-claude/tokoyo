# 参考画像の指示書（ChatGPT / Gemini に依頼する文）

主人公・妖怪・ボスを、コードで3Dに作り込むための「見本の絵」を作る指示書です。
できた画像はこのフォルダ（`design-notes/lookdev/refs/`）に置きます。仕様の元は `docs/12_visual_plan.md` 5章。

## 使い方（3手順）
1. 新しいチャットを開き、**`design-notes/lookdev/reference.png`（今の参考画像）を添付**して、下の「共通の文」と「個別の文」を続けて貼る。まず**正面**を作る。
2. 気に入った正面が出たら、**同じチャットのまま**「同じキャラクター・同じ服・同じ色で、真横（左向き）を」「背面を」と頼む。別のチャットにすると別人になりやすい。
3. 画像を保存し、下の表のファイル名にしてこのフォルダへ置く。1体につき3〜5回作り直して一番良いものを選ぶ。

うまくいかないとき
- 向きごとに顔や服が変わる → 正面の画像を添付し直して「この画像と同じ人物で」と書く。
- 背景に風景が入る → 「背景は無地の生成り色だけ。地面の影も描かない」と追記する。
- ポーズが付く → 「武器を構えない。まっすぐ立つだけ」と追記する。
- 3方向を1枚にまとめた絵（三面図）が出てもよい。その場合は1枚のまま `hero_sheet.png` のような名前で置く。

## 共通の文（毎回、最初に貼る）
```
添付した水彩画と同じ画風で、3Dモデルを作るための設定画を1枚描いてください。

【画風】
・添付画像と同じ、細い墨線と淡い水彩の日本画風イラスト。色は渋く落ち着いた色
・紙の質感と、絵の具のにじみを残す
・線は細く、服のしわ・縫い目・ほつれ・木目・毛並みまで描き込む

【構図】
・1体だけを、頭の先から足の先まで全身が入るように描く
・背景は無地の生成り色（明るいベージュ）だけ。風景・地面・影・文字・枠は描かない
・カメラは目の高さで真正面から。あおりや見下ろしにしない（遠近のゆがみなし）
・まっすぐ立った姿。ポーズや動きは付けない
・光は左上からのやわらかい光。強い逆光や濃い影にしない
・横長ではなく縦長の画像（縦 1536px 以上）

【向き】
今回は「正面」を描いてください。
（このあと同じキャラクターで「真横（左向き）」「背面」も頼みます）
```

## 個別の文（共通の文の後ろに続けて貼る）

### 1. 主人公（楓真）— ファイル名 `hero_front.png`・`hero_side.png`・`hero_back.png`
```
【描くもの】添付画像の中央に後ろ姿で立っている若い剣士と同じ人物。
・18歳くらいの男性。6頭身前後、すらりとした体。黒髪の短めの髪で、後ろを小さく結っている
・萌葱色（くすんだ深い緑）の羽織。袖は広く、袂が垂れる。なで肩。衿に白い半衿が少し見える
・墨色（こげ茶がかった濃い灰色）のひだの深い袴。帯は暗い赤
・白い長い鉢巻。後ろに2本の長い尾が垂れる
・白い脚絆と草鞋
・両腕は体から少し離して自然に下ろす。手には何も持たない（武器は別に描く）
・表情は静かで引き締まった顔
```
追加で頼むと助かるもの
- 顔の寄り：「同じ人物の顔を、正面と斜め前から大きく」→ `hero_face.png`
- 武器：「この人物が使う長巻（ながまき。柄の長い大太刀）だけを、横向きに1本。柄は暗い赤の柄巻、金色の鍔、石突、柄頭に赤い房」→ `hero_weapon.png`

### 2. 提灯お化け（灯魂）— `chochin_front.png`・`chochin_side.png`・`chochin_back.png`
```
【描くもの】添付画像で鳥居から下がっている提灯のお化け。
・古い和紙の提灯。細い竹の骨が横に何本も通る。紙は黄ばみ、あちこち破れてめくれている
・正面に大きな一つ目（重いまぶた、琥珀色の瞳）
・目の下に横に裂けた口。口から長い桃色の舌が、提灯の高さより長く垂れて先が丸まる
・上と下に黒い漆塗りの輪（蓋）。上に鉄の吊り金具（鉤）
・下半分は煤けて暗い
・宙に浮いた状態で、吊り金具の先まで入れる
```

### 3. 唐傘お化け（唐笠）— `karakasa_front.png`・`karakasa_side.png`・`karakasa_back.png`
```
【描くもの】添付画像の右寄りにいる、破れた傘のお化け。
・半分ほど畳んだ古い和傘。暗い緑がかった色。骨が何本も通り、折り目がはっきりある
・縁はぼろぼろに破れて垂れ下がり、ところどころ穴が開いている
・傘の正面に大きな一つ目とまぶた、その下に口と垂れた舌
・傘の下から人の素足が1本だけ出ている。膝があり、高い下駄を履く
・傘のてっぺんに短い石突
```

### 4. 山犬（穢狗）— `yamainu_side.png`・`yamainu_front.png`・`yamainu_back.png`
```
【描くもの】添付画像の右奥の岩の上にいる、黒い山犬の妖怪。
・痩せて骨ばった大きな犬。胸が深く、腹が締まっている。脚は長く細い
・毛は暗い灰色。首から背中にかけて、墨が逆立ったような長い毛（たてがみ）
・長い鼻先。口を少し開けて牙が見える。耳は後ろへ寝かせている
・目だけが青緑に光る
・尾は下げている
・四本足でまっすぐ立った姿（頭を上げた自然な立ち姿）

```
※ 四つ足は真横が一番大事なので、真横 → 正面 → 背面の順に頼む。

## 作る順と、選ぶときの目安
- 順番：主人公 → 提灯お化け → 唐傘お化け → 山犬 → 白雪・岩丈 → 面鬼 → ボス。**主人公の3枚だけ先にあれば作業を始められる**。
- 良い画像の目安：全身が切れていない／背景が無地／正面・横・背面で服と色が同じ／手足や武器の本数がおかしくない。
- 細部が少し違っていても構わない（3Dにするとき、3枚を見比べて決める）。
