## 1. 時間規則の実装

### 1.1 倍率（09 4.2 の具体化）
- `scale(e) = q(worldMul × indivMul(e) × hs(e))`、`q(x)=round(x×4096)/4096`。`localF(e) += scale(e)`（毎実t）。
- `worldMul = fuWorldMul(0.15，構え中) × tutorialMul(0〜1，導入のみ。01の提案)`。それ以外 1。
- `indivMul(e)`：個別倍率の積。現行は見切り減速 `mikiriSlowMul`=0.3 のみ（同じ種類は重ねない。見切りを2回取っても0.09にならない）。
- `hs(e)`：`tick < hitstopUntil(e)` なら0、それ以外1。命中した tick T に `hitstopUntil = max(現値, T+1+hitstopF)`。
- 世界倍率・個別倍率の変化は**決めたtickの次のtickから**効く（scaleは各tickの段2で先に決まるため）。見切り減速は `slowUntil = T+1+90`。
- 技のフレーム `moveF = floor(localF − moveStartLocalF)`。局所タイマーは「開始時の localF＋長さ」と比べて判定する（減算しない）。
- 連続量（移動・技の前進・ノックバック・弾）は `×scale/60` で積分。ポーズは小数の moveF で補間（×0.15でも滑らか）。

## 2. 技のデータ構造（MoveDef は 09 3章の型。Q1〜Q6 は 09 v1.1 で採用済み）

### 2.1 フィールドの意味

| フィールド | 意味・規則 |
|---|---|
| `id` | `持ち主.技`（例 `fuma.a1`、`shirayuki.ougi3`、共通は `common.kekkai`・`common.fuCast`） |
| `kind` | 09 の列挙。走り攻撃・宙返り射は `ground`・`air` |

本作にガードは無い（A7-1）。「防御不能」という語は使わず、敵側の旗は `ignoreInvuln` だけ。面鬼の正面ガードは04。

### 2.2 座標系と判定の形
- キャラ局所座標：原点＝足元のカプセル底の中心、**+Z＝前、+Y＝上、+X＝キャラの右**。世界へは `w = pos + x·R + y·Up + z·F`、`F=(sin yaw,0,cos yaw)`、`R = F×Up = (−F.z, 0, F.x)`。
- 形は 09 の `HitShape`（球・カプセル）のみ。表の略記は読み込み時に `src/data/moveShapes.js` の純関数でカプセル列に展開する：
  - **弧** `弧 y 内–外 θ0→θ1 r`：高さ y の水平の薙ぎ。θ は+Z から右回り正（`(d·sinθ, y, d·cosθ)`）。fromF〜toF で θ0→θ1 を等速に掃き、各フレームでそのフレームが掃く角度を15°以下に刻んで、内→外のカプセルを並べる（すり抜け防止）。全て同じ hitGroup。
  - **縦弧** `縦弧 内–外 φ0→φ1 r`：支点(0,1.2,0)の縦の振り。φ は真上0°・真前90°（`(0, 1.2+d·cosφ, d·sinφ)`）。刻みは弧と同じ。
  - **球** `球(x,y,z) r`、**筒** `筒(a)→(b) r`（カプセル）。

### 2.3 多段の規則
- `attackInstanceId`：技の開始（f0）ごとに世界の通し番号を1つ。その技の弾・場も同じIDを継ぐ。符の術・封破の余波は新しいIDを取る。
- 命中済み集合 `(attackInstanceId, hitGroup, targetId)`：1組につき1回。`rehitF` がある判定は、その組の前回命中から攻撃側の局所 rehitF f 後に再び当たる。弾の hitGroup は `発射番号×100＋判定の番号`。
- 1つの技が1体に当たる回数＝その技の hitGroup の数（＋rehit）。表の「単体合計」はこの和。
- 集合は技の終了（弾は消滅）時に捨てる。見切りで避けた攻撃も「命中済み」に入れる（以後プレイヤーに当たらない）。

### 2.4 キャンセル・先行入力
- 先行入力：ボタンの `pressed` を8実t保持（ヒットストップ中も数える）。窓が開いた最初のtickに、保持中で最も優先の高いものを1つ実行し、**保持を全て捨てる**。優先：回避＞奥義＞結界＞符＞攻撃＞跳躍（core 7.2 に結界・符を追加、提案C2）。
- 表の **連**＝次の段（→先）へ移れる最初の f。**避**＝回避・跳躍・奥義の溜め・結界・符へ移れる最初の f。**移動**：避＋6f 以降、スティック長≥0.3 で技を終えて歩き・走りへ。
- 一時停止に入ったら先行入力を全て捨てる。
- 向き：地上技は f0〜2 の間、02 のソフトロック対象（無ければスティック方向）へ即座に向く。以後は固定。踏み込みの距離は02（白雪は無し）。
- 空中技：開始時に上向き速度を0にし、技の間の重力×`airAtkGravMul`(0.3)。各空中技は1滞空に1回（白雪の空射は3回）。空中技の途中で着地したら技を終え、着地硬直 `airLandLagF`(6)。
- 空中の水平移動の上限（02 3.5 の到達の規則を守るため）：1回の滞空で空中技（`air`）の `motion` による水平移動は合計 `airAtkMoveMaxM`(1.0m) で打ち切る（表の値は全て内側：楓真 air2 0.3m）。神通足攻撃（`dash`）の前進は、その滞空の神通足で既に動いた水平距離との合計が `airDashAtkTotalMaxM`(4.5m) に達した tick から0にする（判定は続ける）。例：神通足の6f目（2.25m）で疾風突き → 前進は3.0mではなく2.25mで止まる。02 3.4 の安全弁はこれとは別に常に働く。

### 2.5 走り攻撃の条件
水平速度≥`runAtkMinSpeedMps`(5.5) が直前 `runAtkMinF`(15) 実t続いた接地中の攻撃押下。

### 2.6 弾（ProjectileDef は 09 の型。`pierceMaxCount?`・`area?` を含む）
- 発射：`offset` から。方向＝①注目対象 ②02 のソフトロック対象（射程は技ごとの値）③（一穴のみ）カメラ前方±20°・30m内の穢石・穢核 ④向き（一穴はカメラ前方、ピッチ−10〜+30°）。狙う点は対象カプセルの中点。
- 移動：09 6.5 の刻み。`lifeS = 射程/速度`。誘導は `homingDegPs` で、対象が進行方向の±40°内のときだけ曲げる。
- 当たり：被弾カプセル→命中（ダメージ等は弾の damage と、発射した技の knockback・hitstopF・breakDmg）。`pierce=false` は1体で消える。`pierce=true` は `pierceMaxCount`（省略＝無制限）体まで貫く。地形・projBlock 形状で消える。
- 弾はヒットストップで止まらない。射撃・術の命中では撃った側も止まらない（`attackerStops` の既定：strike=true、shot・spell=false）。
- 場（`area:{rM,hM,delayF,rehitF,hitCount,finalDamage?}`）：速度0の弾。置いて delayF 後から rehitF ごとに hitCount 回、円柱内の全敵へ当たり、最後に finalDamage を1回。

### 3.2 照合の手順（09 4.3 段5・6の中身）
1. 弾を ID 順に移動し、触れたものを候補に入れる（段5）。
2. 近接の判定：`scale>0` の攻撃者だけ、現在の moveF に有効な hitboxes を世界座標にする（**ヒットストップ中の攻撃者は新たに当てない**）。
3. 被弾側：敵対する全エンティティのカプセル＋プレイヤーの残像（6章）。無敵中は「触れた」とだけ記録する。
4. 候補を（陣営：プレイヤー側が先、攻撃者ID、hitGroup、被弾者ID）の昇順に並べる。
5. 命中済み集合にあるものを除き、順に適用（ダメージ 10章 → 反応 5.3 → ヒットストップ 5.1 → 結界 7章 → イベント）。
6. **同tickの相打ち**：両方当たる。ただし、そのtickにプレイヤーの命中で怯み以上の反応を受けた敵の攻撃で、判定がこのtickに初めて出たもの（持続の1f目）は無効（プレイヤー有利の同着）。
7. HP≤0 の敵は `kill` を出し、報酬（12章）を与える。プレイヤーの死亡判定は自分のヒットストップが終わったtickに行う（見切りの遡りのため）。

## 5. 手応え

### 5.1 ヒットストップ
1. `hs = hitstopF（技/判定の指定）?? round(基礎×0.5+4)`。上限：通常14、奥義（kind `ougi`）20。
2. 例外：封破の命中＝20、崩れを起こした命中＝20、撃破した命中＝`hs+3`（上限20）。
3. 同じ攻撃が同じtickに N 体へ当たる：`round(hs×[1,0.95,0.9,0.85][min(N,4)−1])` を攻撃側と全被弾者に。
4. 攻撃側：`attackerStops` が真のときだけ止まる。1つの attackInstanceId で攻撃側が止まる合計は上限（14/20）まで（多段で凍り続けない）。
5. 被弾側：`hitstopUntil = max(現値, T+1+hs)`。弾・場は止まらない。ダメージ0の効果（封印の付与）は止めない。

### 5.2 揺れと閃光（描画のみ。被弾カプセルは動かさない）
- 被弾者の揺れ：振幅 `A0 = clamp(0.012×hs, 0.03, 0.15)` m × `clamp(カメラ距離/5.0, 0.8, 1.6)`。k 実t目（0始まり）の変位 `A0×(1−k/hs)×(floor(k/2)偶数?+1:−1)`。地上＝攻撃方向に直交する水平、空中＝上下。攻撃者は×0.25で攻撃方向に。
- 白フラッシュ：被弾した敵は命中のtickから3実t白（07 の uHitFlash）。プレイヤーは朱。

## 6. 見切り

### 6.1 残像
- 回避（ステップ・神通足・宙返り）を開始した tick に、プレイヤーの被弾カプセルの複製（残像）を置く。寿命 `mikiriGhostF`(10、易しい `mikiriGhostEasyF` 14、難しい `mikiriGhostHardF` 8) 局所f。
- 成立の条件（全て）：①敵の近接判定・弾・場が、残像に触れる、または回避の無敵中の本体に触れる ②その技の `ignoreInvuln` が偽 ③その attackInstanceId がまだプレイヤーに当たっても避けられてもいない。
- 成立したら、その攻撃を命中済みに入れる（以後プレイヤーに当たらない。弾は消えずに抜ける）。同じtickに複数成立しても報酬は1回。
- 対象外：ボスの「封」、海・感染などの地形ダメージ。

### 6.2 timeStamp 補正（最大4f遡り）
1. 回避の `pressed` に `ageF=a`（0〜4、09）が付く。プレイヤーの「回避できた状態だったか」を直近5実t記録しておき、`a` を「T−a から T まで連続して回避できた」最大値に切り詰める（ただし被弾による怯みは「回避できた」とみなす。2を参照）。
2. 直近4実tの被弾記録（命中前のプレイヤー戦闘状態の写し：HP・位置・速度・向き・状態機械と moveF・状態異常・溜め・資源）を持つ。T−a 以後に受けた `ignoreInvuln` でない敵の命中があれば、最も古い命中の写しへ戻し、その命中を全て取り消す（`hitRevoked`）。攻撃側の残りのヒットストップは0にする。取り消した攻撃は「避けた」に入れ、最初の1つで見切り成立。
3. 回避は T に f0 から始める（移動距離は減らさない）。判定だけを a 早める：無敵は `[max(0,2−a), 14−a]`、残像の寿命は `ghostF − a`、残像の位置は T−a の位置（09 の位置履歴）。
4. 死亡判定はヒットストップ明けなので、致命打も取り消せる（最小の停止は5実t＞4）。

### 6.3 報酬
- 減速：成立位置から水平 `mikiriRadiusM`(12) 以内の敵と、同じ範囲内の敵の弾、さらに減速中の敵がこの後に撃つ弾に、`slowUntil = T+1+round(mikiriSlowS×60)`（90実t）。ボスも対象。減速中の再成立は時間を90に戻し、範囲内の敵を足す（延長の加算はしない）。
- 結界：`slowUntil` 中のプレイヤーの結界は所持を減らさない（**所持0でも張れる**）。
- 札：+1。ただし前回の札の加算から `mikiriFudaCdS`(2.0) 実s未満なら0（`mikiri.fuGain`）。感染中は12章の半分規則。
- 演出：`mikiri` イベント（朱印・残像3体・uInk・拍子木は 01/07/08）。

## 7. 結界

### 7.1 張る（`common.kekkai`：発8/持1/硬11=20、避12。地上・空中とも可、空中は重力そのまま）
0. 所持0（見切り減速中を除く）→ 何もせず `kekkaiFail{reason:'noCharge'}`（技も出さない。ボタンは灰、01）。
1. 押下の f0 で対象を決める：①注目対象 ②02 のソフトロックの評価関数を距離 `kekkaiRangeM`（楓真・岩丈8、白雪15）で使った最良 ③無し → 罠。除外：封印中・死亡・ボスの再封印不可中・崩れ中・`sealable=false`。ただし①の注目対象、または②で除外前に最良だった敵が**ボスの再封印不可中**なら、罠にせず `kekkaiFail{reason:'cooldown'}`（消費なし）。
2. f8 で再確認：生存・除外なし・距離 ≤ 範囲＋1.5m → 封印し所持−1（見切り減速中は0）。外れた → 消費なし `kekkaiFail{reason:'range'}`。
3. 罠：前方4mの地面（海・崖・禁止の升なら自分へ向けて0.5mずつ戻し、1m未満なら足元）。同時に1つ。罠が既に1つあるときは置かず、消費なしで `kekkaiFail{reason:'trapLimit'}`（第3回統合で変更。古い罠を消して置き直す規則は廃止）。半径1.5m・高さ2.0mの円柱に、封印できる敵のカプセルが触れたら封印して罠は消える。寿命10s（`kekkaiBreak` reason `trapTimeout`）。

### 7.2 所持と回復
- 上限 `CharacterDef.kekkaiMax`（3、強化で5。ゲージ100のボス戦は+1）。所持＜上限の間、1つの回復タイマー8s（プレイヤー局所）が走り、満ちたら+1・`kekkaiCharge`・まだ上限未満ならすぐ次を数える（**順番に1つずつ**）。消費してもタイマーはリセットしない。

### 7.3 封印の効果（敵）
- 長さ `kekkaiSealS`(5)s、大型・ボスは×0.5（2.5s）。封じられた敵の局所時間で数える。
- 行動停止：AI・技を止め、出ていた判定は消す（撃ち済みの弾は残る）。攻撃権を返す（04）。重力なし（空中ならその場）。ノックバック・反応なし（ヒットストップはかかる）。被ダメ×1.5（結界倍率）。
- 新しい attackInstanceId の命中ごとに残り−1s（多段は1技で1回）。0以下で解除（`kekkaiBreak` reason expire、命中で尽きたら hits）。ボスは解除から10s 再封印不可。
- 面鬼の正面ガードは封印中は無効（04）。

### 7.4 封破
- kind `ougi` の技が封印中の敵に当たる → 封印を解き `fuhou` イベント。その命中と、**同じ attackInstanceId のその敵への以後の命中すべて**に結界倍率 `fuhouMul` 2.0（大型・ボス `fuhouBigMul` 1.5）。
- 封破の命中：停止20、崩し×2.0（その1発のみ）。
- 余波：その敵の中心から2.5m内の他の敵へ、新しい attackInstanceId で威8・術・使用者の属性・反応「中」（放射）。余波は封破を起こさない（封印中の敵には×1.5・−1sの通常扱い）。

### 7.5 敵からプレイヤーへの結界（ボスの「封」）
- 状態 `sealed`：移動・全行動不可、被ダメ×1.5、`playerSealed{on:true}`。溜め・符の構えは取消。
- 攻撃の `pressed` 8回で脱出、または4.0s（プレイヤー局所）で自動解除。脱出後は即行動可・無敵なし。

### 10.1 相剋の表（攻撃側→防御側。○＝×1.5、×＝×0.75、空欄＝×1.0。属性なしは全て1.0）

|---|---|---|---|---|---|
| 木 | | | ○ | × | |
| 火 | | | | ○ | × |

| 水 | | ○ | × | | |

相生（木→火→土→金→水→木）は戦闘倍率なし。龍穴（05）でのみ使う。

### 10.2 計算の順番（浮動小数の順序も固定）
```
atkMul    = 強化の攻撃倍率(06) × 醒1.3 × 龍穴の弱体0.75
elemMul   = 10.1
sealMul   = 封印中1.5 ／ 封破2.0（大型・ボス1.5）／ プレイヤー被封印1.5 ／ それ以外1
statusMul = 防御側の 醒0.7 × ゲージ100のボス戦0.85(プレイヤー) × 崩れ中の倍率(04)
            （感染は被ダメに影響しない：×1.0）
mul   = min(atkMul × elemMul × sealMul × statusMul, dmgMulCapMul=3.0)
final = max(1, round(基礎 × mul × damageTakenMul))   // damageTakenMul＝1−防御軽減。岩丈0.85、面鬼の正面ガード等は04
```
- 例：醒の楓真が封破（小型・土）：1.3×1.5×2.0=3.9 → 3.0。
- 感染の減少・海の8%は式を通さない（最大HPの割合、05）。
