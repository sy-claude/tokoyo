## 0. 表記の約束
- 単位：距離=m、速度=m/s、角度=度（deg）、時間=f（60Hzの1tick）または s、画面=CSS px。
- f と s：短い動作（技・無敵・先行入力）は整数f。長い効果（状態異常・回復）は s。読み込み時にtickへ換算。
- 設定値の名前は camelCase ＋単位の接尾辞：`F`（フレーム）`S`（秒）`M`（メートル）`Mps` `Mps2`（加速度）`Deg` `DegPs` `Px` `Mul`（倍率）`Pct`（%）`Hz` `Db`（音量）`Bpm`（テンポ）、無次元は `Count`（個数・回数・点数）`Ratio`（重み・閾値など）。例：`dodgeTotalF`, `runSpeedMps`, `camFovYDeg`。この規則は値が数値スカラーのキーに適用し、配列・オブジェクト・文字列・真偽値のキーは対象外（表の単位の欄は書く。09 2章8）。
- すべての調整値は `src/config/*.js`、すべての技・敵・キャラ・ステージは `src/data/*.js`。詳細設計書の数値表は「configキー｜値｜単位｜説明」の形で書き、実装はその表を写す。**コードへの数値の直書き禁止**。
- 「左右」は右利き配置での表記。左利き設定では反転（例外は各所に明記）。

## 1. 作品
- 仮題『常世祓（とこよばらい）』。和風・陰陽五行の三人称3Dアクションアドベンチャー。スマホブラウザ、横画面、タッチ操作。
- 着想元は双界儀（1998）。**固有名詞・キャラ・物語は流用しない**。仕組みの骨格と雰囲気のみ。
- 試作のゴール：**1ステージ「霜月・白鷺岬」＋ボス1体を、3人から1人を選んで遊び切れる**。物語は章題と数行の字幕のみ。

### 1.1 設計の三原則
1. **一つの操作には一つの意味**（例外：回避ボタンは空中で神通足／白雪は宙返り）。
2. **深さはボタン数ではなくタイミング**（見切り、奥義の段、封破の瞬間、符を描く速さ）。
3. **祓いが手触りになる**（穢れを祓う行為が、進行・戦術・演出・音のすべてに通る）。

### 1.2 視覚の憲法（詳細は07）
1. 紙が主役、墨が骨、朱は情報、金は祝福。色の意味を混ぜない。
2. 明度の三層：背景は明（70〜95%）、体は暗（15〜45%）、危険は「暗い芯＋明るい縁」、味方の弾は「明るい芯＋属性色の縁」。**白黒にしても遊べること**。明度は sRGB の Y（`0.2126R+0.7152G+0.0722B`）で測る。背景の陰面は0.55以上かつ背景面積の30%以下。例外：地上2.5m以上の物・千本鳥居の柱・崖の墨線・文字（測り方の詳細は07 1.2）。
3. 最高彩度の朱 #e2452b はゲーム情報専用。環境の朱は #a3412e 以下（例外は夕日 #d9502e のみ。空にあり方位の目印）。
4. 加算合成は暗い面の上と1〜3fの閃光だけ。発光体は墨の縁で囲む。

## 3. コアループ
1. タイトル：「音を出して遊ぶ／音なしで遊ぶ」（このタップで音声起動・Androidの全画面化・画面消灯防止）
2. キャラ選択：回転する五芒星に3人。相性3軸（ボス／道中／探索：◎◯△）と一言。魂片で強化。
3. ステージ（10〜15分）：倒す・祓う・壊す → 地脈ゲージ ↑。50で**ボスの鳥居**が開く（光柱＋夕日の方向）。
4. ボス戦（2段階、目標2.5〜3.5分）。
   - **再挑戦は「記録地点から」が既定**。記録地点＝05のチェックポイントとボスの鳥居（鳥居の後は鳥居だけ。表示は「ボス前から」）。どの記録地点からでも勾玉は最低3。復元の内容は06 8章。
5. 結果（時間・魂片・浄化率）→ キャラ選択へ。
- 魂片は拾った瞬間に保存。死亡でも失わない。穢石の魂片は初回のみ満額（朱3・黄7・蒼12）、以降は1。ボス撃破は初クリア10・以降3。小型の敵は10%で1、大型は2。記録地点から戻った同じ挑戦（run）の中では、一度払った穢石の魂片と、一度判定した敵の落とし物は二度出ない。
- 初回は浜の参道で導入（操作を1つずつ解放）。2回目以降は省略可。

## 4. 時間の規則（M0で固定・変更禁止）
- **実tick**：60Hzの固定更新の回数（整数）。一時停止で止まる。
- **局所時間**：実tick × 各エンティティの時間倍率。倍率 = 世界倍率 × 個別倍率 × ヒットストップ倍率（0か1）。
  - 世界倍率：通常1.0、符の構え中0.15（自分を含む全員）、導入中は台本が指定する倍率（0〜1。例：最初の予兆で0.2、最初の符で0。05の台本）。複数は掛け算。
  - 個別倍率：見切りの減速（敵×0.3）など。
  - 倍率は積を `q(x)=round(x×4096)/4096` で丸める（1/4096 単位）。倍率の変化は、変えると決めたtickの**次のtickから**有効。
- **実tickで数えるもの**：ヒットストップの長さ、先行入力、見切り減速の長さ、符の構えの制限時間、奥義の溜め、カメラ、UI、音。
- **局所時間で数えるもの**：それ以外すべて（技のフレーム、無敵、予兆、状態異常、結界、回復）。
- 1回の描画で進めるtickは最大5（それ以上は捨てて遅延を許す）。描画は前後tickの補間。

## 5. 操作（詳細は01）
- 左：移動スティック（ハイブリッド式）。右：攻撃・回避・跳躍・奥義・結界・符・注目のボタン。右側の空き領域のドラッグ＝カメラ、敵のタップ＝注目。
- **攻撃**：タップで連撃。長押しの意味はない（押したまま28px動かすとカメラ操作）。
- **回避**：地上＝ステップ（スティック中立なら後方）、空中＝神通足（白雪は宙返り）。
- **奥義**：長押しで溜め、離して発動。回避ボタンへ滑らせると取消して回避。押下点から72px離すと取消。取消域から56px以内に戻ると**0から**溜め直す。
- **結界**：タップで対象に結界。対象がいなければ前方に罠を設置。
- **符**：符の構え（世界×0.15）→五芒星をなぞる→離すと発動。
- **注目**：敵がいれば注目、注目中なら解除、敵がいなければカメラを背後へ戻す。
- 入力は毎tick `InputFrame` にまとめてシムへ渡す。タッチ・キーボード・テスト・リプレイは同じ形式。型は09 3章が唯一の正本。

## 6. 移動・カメラ（主要値。詳細と全キーは02）
- 走6.5 m/s、歩2.5 m/s、最高速まで0.12s、停止0.08s、旋回900°/s、カメラ基準の自由移動。
- 跳躍：高さ2.4m、上昇0.35s、落下重力×2.0、早離しで上昇速度×0.45（離陸から12f未満の離しは12f目に適用＝最低12f保持、最低の高さ1.96m）、コヨーテ6f、先行入力8f、空中制御65%。
- 神通足：1滞空1回、12f・4.5m水平、重力無視、無敵2〜9f。宙返り（白雪）：上1.0m・後方2.5m、無敵あり。
- ステップ：全体24f・4m・無敵2〜14f・18f目から取消可。
- **到達の規則**：必須経路は水平2.5m・段差1.8m以下。神通足前提の経路は5.5〜6.5m。越えてはならない隙間は10m以上、登れてはならない壁は3.6m以上。乗れる面（地面・乗れる小道具の上）を、水平4.8m以内の歩ける地面から2.5〜3.5m高い所に置かない（白雪の宙返りで届いてしまうため）。強化で開く場所は作らない。神通足を使う前（白雪は常に）の空中の水平移動は、最後に接地した点から4.8mで頭打ち。空中技の水平移動は1滞空1.0m以下、神通足攻撃はその滞空の神通足と合わせて4.5m以下（03 2.4）。

## 7. 戦闘（詳細は03）
### 7.1 ダメージ
```
最終 = 基礎 × 攻撃倍率 × 五行倍率 × 結界倍率 × 状態倍率 × (1 − 防御軽減)
五行倍率：相克で勝つ ×1.5 ／ 負ける ×0.75 ／ その他 ×1.0
  相剋（AがBに勝つ）：木→土→水→火→金→木
  相生（AがBを生む）：木→火→土→金→水→木 （戦闘倍率なし。龍穴でのみ使う）
結界倍率：封印中 ×1.5 ／ 封破 ×2.0（ボス・大型は ×1.5）
倍率の積（攻撃・五行・結界・状態）の上限 ×3.0。端数四捨五入、最低1。
```
- ダメージ種別：**打**（近接）・**射**（矢・弾）・**術**（符・奥義の術部分）。穢石と穢核は打・射・一穴でのみ壊れる。

### 7.2 技と手応え
- 技はすべてデータ（`startupF/activeF/recoveryF/cancels/hitboxes/motion/damage/hitstopF/knockback/breakDmg/armorF/invulnF/pose`）。
- 先行入力8f（ヒットストップ中も数える）。優先：回避＞奥義＞結界＞符＞攻撃＞跳躍。窓が開いた最初のtickに、保持中で最も優先の高いもの1つだけを実行し、残りは捨てる。
- ヒットストップ：`round(基礎ダメージ×0.5+4)` f、上限 通常14f／奥義・封破・崩し20f。撃破の一撃は+3f（上限20）。攻撃側と被弾側を同時に止める（キャラ単位、全体停止禁止）。射撃・術の攻撃側は止めない。攻撃側が止まる合計は1技（attackInstanceId）につき上限（14／20）まで。複数ヒットの割引 2体×0.95・3体×0.9・4体以上×0.85。

### 7.3 見切り
- 回避開始位置に**残像の被弾判定**を10f（易しい14f・難しい8f）残す。残像または無敵中の本体に敵の攻撃判定・弾・衝撃波が触れたら成立。同じ攻撃（`attackInstanceId`）で1回まで。見切られた攻撃はその後プレイヤーに当たらない。入力はイベントのtimeStampで最大4f遡って補正。
- 対象外：ボスの「封」（`ignoreInvuln`。見切り不可で、回避の無敵も貫く）、地形のダメージ。
- 報酬：半径12m内の敵（とその弾）を×0.3で1.5s（実tick）／その間は結界の消費なし（**所持0でも張れる**）／札+1（2sに1回まで）／「見切」の朱印。

### 7.4 陰陽術（詳細は03）
- **結界**：所持3（強化で5、地脈100のボス戦では+1で最大6）、1回分の回復8s（順番に1つずつ）。封印は最大5s、被ダメ×1.5、命中1回ごとに残り−1s（多段技は1技で1回）。奥義の命中で封破：封印を割った奥義の、その敵への以後の全命中（同じ attackInstanceId）に×2.0（大型・ボス×1.5）。封破の余波は封破を起こさない（連鎖しない）。罠は同時に1つ・10s（既に罠があるときは置かず失敗、消費なし）。ボス・大型は効果時間半分、ボスは封印解除後10s再封印不可、崩れ中は無効。
- **奥義**：段 0.6s／1.2s／2.0s（実tick）。消費 勾玉1/2/3（上限9）。0.6s未満で離すと不発（消費なし）。溜めは**地上のみ**（空中の押下は着地のtickから溜め始め、溜め中に接地を失ったら取消）。溜め中は最高速＝走り×0.4（楓真・白雪2.6m/s）・無敵なし・被弾で取消（消費なし）。発動中はスーパーアーマー。各キャラ3段の技は03で定義。
- **封陣符**：画数＝段、1画＝札1。属性＝最初に触れた点の属性。
  | 画 | 名 | 効果（詳細は03） |
  |---|---|---|
  | 1 | 一穴 | 貫通する光の矢（術。穢石・穢核も壊せる） |
  | 2 | 浄 | 半径6mの穢域を浄化、感染を治す、HP10%回復 |
  | 3 | 守 | 札の障壁8s（敵弾を消す、接触ダメージ） |
  | 4 | 滅 | 画面内・20m以内の全敵に中ダメージ＋怯み |
  | 5 | 醒 | 15s 攻撃×1.3・被ダメ×0.7 |
  - 符の構え：**地上のみ**・無敵なし・移動不可。最初の接触まで1.5s、描き始めから3.0s、指を離しても0.25sは継続、5画で即発動。構え中の被弾は取消（札の消費なし）。描き始める前に限り、左手側（スティック範囲）のタップで手動取消（消費なし）。取消後1sは再構え不可。
  - 札：上限8（キャラ・強化で変動）。回復：撃破+1、穢域1つにつき+2を1回だけ（穢核の破壊・浄化のどちらでも）、見切り+1。感染中は回復半分。

### 7.5 敵の攻撃管理
- 攻撃権：全体2枠（易しい1／難しい3）。費用は通常1・強攻撃2・特殊2、射撃は1。同時に攻撃権を持てる射撃型は1体まで。ボスは攻撃権の対象外。攻撃権の時間（配る間隔・冷却・予約）は**世界時間**（世界倍率だけ掛けた時間）で数える（符の構え明けの一斉攻撃を防ぐ）。
- 予兆：予兆＝予兆の開始から判定の開始まで。通常0.5s、強0.9s、特殊1.2s（ボスの**封**だけ1.0s）。難易度で伸縮（易しい×1.25・難しい×0.85）し、下限0.45s（27f。漢字の0.4sより短くしない）。判定の0.4s前に頭上へ漢字（**撃**＝強攻撃、**穢**＝穢域を作る大技・予兆中に潰せる、**封**＝プレイヤーへの結界・範囲から出れば避けられる）。通常攻撃は漢字なし。
- 画面外の予兆は自キャラの周り半径90pxの円上に朱の矢印。
- プレイヤーの被弾：怯み（12〜20f）／吹き飛び（ダウン→起き上がり45fは無敵）。崖際では海へ落ちない（ノックバックを崖の手前で止める）。

## 8. ステージ「霜月・白鷺岬」（詳細は05）
- 約140m×110m、夕刻。4区画：①浜の参道（導入）②磐座の丘（高低差）③千本鳥居の崖道（細道・海）④岬の先のボス舞台（直径34m）。
- 地脈ゲージ：小型撃破+3／大型+8／穢域浄化+8（敵が作った穢域は+2）／穢石 朱+10・黄+14・蒼+18。最低限の行動で50（白鷺岬は57）、全部で約145（小型20・大型2・初期の穢域2・穢石4。上限100）。
- 目標表示：ゲージ50未満は最寄りの穢れ、50以上はボスの鳥居（光柱）。
- 海：直前の安全地点へ戻す・最大HPの8%・復帰後1s無敵。浜の波打ち際（陸の高さ0.4m未満）は歩けない（禁止の升）。海に落ちるのは崖からのみ。
- 龍穴：同属性または相生の親＝HP 2%/s回復＋感染治療／天敵の属性（自分に勝つ）＝攻撃−25%を15s／その他＝1%/s。1回の滞在で最大40%、使い切りで60s休止。
- 感染：穢域に連続2s以上で発症、HP 0.8%/s（最低1残る）、12sで自然治癒、札回復半分。

## 12. 技術の不変条件（M0で固定。詳細は09）
1. 60Hz固定更新、整数tick、決定論（シード付き乱数・ID順更新・`Math.random`/`Date.now`/`performance.now` をシムで使わない）。決定論は同一JSエンジン内（Node と Chromium の V8）で保証する。実機（iPhone の JavaScriptCore 等）で記録した入力の再生は近似の再現にとどまる。
2. 時計2つ・倍率は掛け算（4章）。
3. カメラはシム側。描画は補間するだけ。
4. シムへの入力は `InputFrame` のみ。リプレイは `InputFrame` の列。
5. シム（`src/sim`, `src/core`, `src/gen`）は描画・DOM・音を知らない。threeは数学クラスのみ可。
6. 衝突と見た目は同じステージデータから作る。攻撃判定は骨に依存しない。
7. キャラ・敵・ボスは「1体＝1メッシュ＋1素材（輪郭込み描画命令2）」。見た目は外部の GLB 素材（11_assets）を優先し、無ければコードの剛体スキン（07 §6）に自動で戻る。ポーズの補正は純関数。（U8）
8. 数値は config と data のみ。名前に単位。
9. 保存は `tokoyo:` 名前空間＋版番号＋移行関数＋引き継ぎ文字列。
10. 描画命令は戦闘中110以下（テストで検査）。後処理は1パス。DPR上限1.5。
11. 色は `THREE.Color` を通す。依存は版を固定（three, vite, typescript, playwright の4つのみ。型定義パッケージも足さない）。BGM ファイルは npm の依存ではなく `public/audio/bgm/` の静的ファイルとして許可する（無くても無音で動く）。実行時に読む外部ファイルはこれと manifest・icon、および **`public/assets/` の素材（GLB・質感画像。11_assets、U8）**。GLB の読み込みは three 同梱の `three/examples/jsm` を使い、npm の依存は足さない。素材の変換に `npx` の道具を一時的に使うのはよい（依存に足さない）。
