- 祓人の歩く・走る・跳ぶ・神通足・宙返り・ステップ・海への落下と復帰を、状態機械と数値で実装できる。

## 0. 前提
- 座標：Y上、+Z が前（09）。プレイヤーの向き `yawDeg`。水平の向きは XZ 平面。
- 時間：移動・状態・無敵は**局所時間**（`scale` を掛ける、09 4.2）。カメラ・先行入力・安全地点の記録は**実tick**。表の f は局所f。
- 積分：重力のある縦は定加速度の厳密式 `y += vy·dt + ½·a·dt²; vy += a·dt`（`dt = scale/60`）。水平は `pos += vel·dt`。半陰的オイラーは使わない（頂点が0.1m低くなるため）。
- 衝突の解決は 09 6.3 の `move(c,dx,dz,dy)`。段差0.4m（`stepUpM`）、45°超は壁（`slopeMaxDeg`）、下りの吸着0.4m（`stepDownM`）は `config/collision.js` の値をそのまま使い、本書では再定義しない。
- 入力：09 の `InputFrame`（`stick` y=前+、`camDeg` 感度適用後の度、`flick`、`taps`）。`camHeld:boolean`（カメラ系の指が触れている）も 09 v1.1 の InputFrame に入った。px→度の換算は入力層が本書の `camYawDegPerPx`/`camPitchDegPerPx` で行う（09 3章）。
- 先行入力は `config/combat.js` の `inputBufferF`（8f、実tick、03）を共用する。優先は 回避＞奥義＞結界＞符＞攻撃＞跳躍。窓が開いた最初のtickに1つだけ実行し、残りの保持は捨てる（core 7.2、03 2.4）。

## 1. プレイヤーの状態機械（`sim/player/fsm.js`）

### 1.1 状態一覧
地上の移動系＝`idle/walk/run/land`。攻撃・奥義の溜め・結界・符は `action`（中身は03）。`event` は導入・ボス登場などの操作不能区間（05/04 が入れて出す）。

| 状態 | 入る条件 | 毎tick | 出る条件 → 次 |
|---|---|---|---|
| idle | 接地で移動入力なし、速度0 | 減速（2.2）。安全地点の記録対象 | 入力 → walk/run。跳躍 → jumpRise。回避 → step。行動 → action。足場消失 → jumpFall（コヨーテ開始） |
| walk | 接地、`|stick|` が 0.15以上 0.55未満（run からは 0.50 未満） | 2.2 の地上移動（目標 2.5m/s×係数） | 同上。倒し量で run/idle |
| run | 接地、`|stick|≥0.55` | 2.2（目標 6.5m/s×係数） | 同上 |
| jumpRise | 地上またはコヨーテ中に跳躍（先行入力含む） | 上昇重力、空中制御（3.3）、早離し（3.2） | `vy≤0` → jumpFall。空中で回避 → airDash/flip。空中攻撃 → action。着地（天井ではなく足場）→ land |
| jumpFall | jumpRise の頂点、足場から落ちた、空中行動の終わり | 落下重力（×2.0）、空中制御、終端速度 | 着地 → land または landHeavy。回避 → airDash/flip（未使用時） |
| airDash | 空中で回避、`canAirDash`、この滞空で未使用 | 4章 | 12f 経過・壁 → jumpFall。6f以降の攻撃 → action（03 の神通足攻撃） |
| flip | 空中で回避、`canFlip`、この滞空で未使用 | 4章 | 24f 経過 → jumpFall。着地 → land。18f以降の攻撃 → action（空中射撃） |
| step | 接地で回避 | 4章 | 24f → idle/walk/run。18f以降は全行動・移動で取消 |
| land | 着地、落下高さ < 4.5m | 地上移動をそのまま処理（速度は保つ）。見た目だけの状態 | 4f → idle/walk/run。跳躍・回避・行動は1f目から取消 |
| landHeavy | 着地、落下高さ ≥ 4.5m | 水平速度0、移動入力無視 | 16f → idle。10f以降は跳躍・回避・行動で取消 |
| action | 03 の技が始まった | 03 が水平移動を `motion` で与える。02 は崖止め（2.5）と衝突だけ | 技の終わり → 接地なら idle、空中なら jumpFall。被弾・海は割り込む |
| hitstun | `playerHurt` kind=flinch | 吹き飛ばし速度を減衰（τ0.15s）。空中なら重力。移動入力無視 | 技の `stunF`（03、12〜20f）経過 → idle（空中なら jumpFall）。再被弾で再開始 |
| launch | 技の knockback.kind=launch | `vy=knockback.vMps`、水平 `hMps`、上昇重力（39.2）のまま放物線 | 着地 → down |
| down | launch の着地、または kind=down | 水平速度を τ0.15s で減衰 | `plDownF`(24f) → getup |
| getup | down の終わり | 移動なし | `plGetupInvulnF`(45f) → idle。`plGetupLockF`(15f) 以降は移動・回避・跳躍・行動で取消（値は03 11.1・`config/combat.js`） |
| fallSea | 09 6.3 の海判定（足が水面−0.3m以下、海・禁止の升）。どの状態からでも | 5章 | 5章の手順 → respawn |
| respawn | fallSea の終わり、死亡からの再開 | 入力無視、20f | → idle（復帰無敵60f開始） |
| dead | HP0（03） | 空中なら落下だけ続ける | 06 の死亡画面 |
| event | 05/04 が指定 | 指定の移動のみ | 指定の終了 |

- 無敵：launch・down・getup の全区間は無敵。getup を移動・回避・跳躍で取消しても開始から45fまで無敵が続くが、攻撃・奥義・結界・符を始めたらその時点で打ち切る（03 11.1 が正本）。
- 割り込みの優先：fallSea ＞ dead ＞ 被弾（hitstun/launch/down）＞ その他。無敵中の被弾は状態を変えない。
- 空中の回避の使用済みフラグ `airEvadeUsed` は接地で偽に戻る。空中で被弾しても戻らない。
- 同じtickに「着地」と「先行入力の跳躍」→ 着地の tick で跳ぶ（land を経ない）。
- 状態名は `GameStateView.player.state` にそのまま出す。

### 1.2 action との接点
- 02 が受け付けて 03 に渡すもの：攻撃・奥義・結界・符の押下（先行入力の解決後）。
- action 中の移動の例外：奥義の溜め中は地上移動を最高速 `runSpeedMps×runSpeedMul×ougiChargeMoveMul`（楓真・白雪2.6m/s、岩丈2.34m/s。キーの正本は本書、03 は参照のみ）で処理（跳躍・回避は03の取消規則に従う）。白雪の射撃中は `walkSpeedMps×shootWalkMul` で歩ける（向きは標的に固定、7章）。符の構え中は移動なし。
- 03 の空中技の `motion` による水平移動も 3.4 の上限を受ける。

## 2. 地上の移動（`sim/player/locomotion.js`）

### 2.1 入力の変換
1. `s = frame.stick`、`m = |s|`。`m < 0.15` は中立。
2. カメラ基準：`yawCam` をカメラの水平向きとして、世界の方向 `d = normalize(R(yawCam)·(s.x, 0, s.y))`。注目中は 8.5。
3. 歩き／走り：`m ≥ 0.55` で走り、走り中は `m < 0.50` で歩きへ戻る（ちらつき防止）。速さは段階式（歩き2.5／走り6.5、中間なし。理由：アニメと試験を単純に保つ）。

### 2.2 加減速と旋回
- 目標速さ `vT` = 歩き `walkSpeedMps×runSpeedMul` ／ 走り `runSpeedMps×runSpeedMul` ／ 中立0。
- 現在の速さ `v` は `vT` へ、加速 `runSpeedMps/runAccelS×accelMul`（54.2m/s²）、減速 `runSpeedMps/runDecelS`（81.3m/s²）で近づく。
- 向き：`yawDeg` を d の方向へ `turnDegPs×turnMul`（900°/s）で回す。速度ベクトル＝向き×v。
- 切り返し：d と向きの差が 120°超、かつ `v > walkSpeedMps` → 向きを d へ即時に合わせ、`v ×= 0.35`。見た目用に `quickTurn` の印を1tick立てる（07）。
- 斜面（45°以下）は水平速度を変えない。45°超・段差0.4m超は 09 の mover が壁として滑らせる。

### 2.3 崖の縁
- 縁の判定：`probe = pos + 向き×(capsule.rM+0.1)`。`heightAt(probe) < y − 1.0` または probe の升が海・禁止なら「縁」。
- 歩き（m<0.55）：縁へ向かう水平成分を0にする（止まる）。縁に沿う成分は残す。
- 走り：止めない。落ちる（コヨーテ開始）。理由：走りで跳ぶ・飛び降りる操作を妨げない。歩きで覗けば落ちない。
- step・action の `motion`・ソフトロックの踏み込み：縁で止める（意図しない海落ちを防ぐ）。
- 被弾の吹き飛び：09 6.3 の `knockbackEdgeStopM`（崖・海から1.0m）で止める（D27）。

### 2.4 キャラ同士の押し合い
- 対象：プレイヤーと敵の被弾カプセル（水平の円、縦の範囲が重なるとき）。
- 重なり量 `o` を重み比で分ける：プレイヤーの移動量 `o × wE/(wP+wE)`。`wP`＝`pushWeight`（キャラ係数）、`wE`＝敵の押し重み（04、目安：小型0.6〜0.8、面鬼3.0、ボス∞）。1tickの押し出し速さの上限 3.0m/s。
- ステップの無敵中（2〜14f）は `wE < 2.0` の敵と押し合わない（すり抜ける）。面鬼・ボスとは常に押し合う。
- 浮遊する灯魂とは押し合わない（04 の `flying`）。

## 3. 跳躍

### 3.1 式
```
g    = 2·H / T²   = 2·2.4/0.35² = 39.18 m/s²  （上昇の重力）
v0   = 2·H / T    = 13.71 m/s
gF   = g × fallGravityMul = 78.37 m/s²       （vy ≤ 0 のとき）
落下 2.4m の時間 = √(2H/gF) = 0.247 s、平地の滞空 = 0.597 s
```
- H=`jumpHeightM`、T=`jumpRiseS`。キャラの跳躍高さは全員同じ（係数を持たない。到達の規則のため）。
- 終端速度 24m/s。天井（walkable 形状の下面）に頭が当たれば `vy=0`。

### 3.2 早離し・コヨーテ・先行入力
- 早離し：jumpRise 中に跳躍が `down=false` になったら `vy ×= 0.45`（1回のみ）。ただし離陸から12f未満の離しは12f目に適用する（`jumpMinHoldF`）。最低の高さ1.96m（タップでも1.8mの段差に届く）、押し続けで2.4m。
- コヨーテ：足場を失ってから6f（`coyoteF`）は跳躍できる。その間は `vy=0` で高さを保つ（落ちながら跳ぶと届かないため）。6f以内に跳ばなければ jumpFall。コヨーテ中の回避は空中扱い（神通足／宙返り）。
- 先行入力：空中で押した跳躍は `inputBufferF`（8f）保持し、その間に着地したら着地tickで跳ぶ。

### 3.3 空中制御
- 離陸時の水平速度は地上速度をそのまま持つ（上限 `runSpeedMps×runSpeedMul`）。step の取消から跳んだ場合も上限で切る。
- スティック入力あり：水平速度を `目標 = d×(歩き/走りの速さ)` へ 加速×0.65（35.2m/s²）で近づける。中立：水平速度を保つ（空中で減速しない）。
- 空中の向き：注目中は標的を向く。それ以外は水平速度が0.5m/s以上なら速度の向きへ `turnDegPs×0.65`（585°/s）で回す。
- 着地硬直：落下高さ＝この滞空の最高点 − 着地点の高さ。4.5m未満は land（4f）、以上は landHeavy（16f）。落下ダメージなし。`land` イベント `{fallM}`。

### 3.4 空中の水平到達の安全弁
- 神通足を使う前（白雪は常に）、最後に接地していた点から水平4.8mより外へ向かう速度成分を毎tick0にする（`airReachCapNoDashM`）。通常の跳躍の最大4.55mでは働かない。宙返り・空中技・被弾で到達の規則を破らないための保険。

### 3.5 到達距離（地面から同じ高さへ、離陸点〜着地点の水平距離。60Hzの数値計算）
| 条件 | 楓真・白雪（6.5m/s） | 岩丈（5.85m/s） | 規則との関係 |
|---|---|---|---|
| 歩き跳び（2.5m/s） | 1.5m | 1.35m | — |
| 立ち跳び（離陸後に走り入力） | 3.35m | 2.9m | 必須2.5m以下に届く |
| 走り跳び | 3.90m | 3.51m | 必須2.5mに余裕1.0m以上 |
| 走り跳び＋コヨーテ6f | 4.55m | 4.10m | 5.5m未満：神通足前提の隙間は跳躍だけでは越えられない（安全弁4.8mでも保証） |
| 神通足：離陸6f後に使用 | 6.13m | 5.96m | 早出しでも6.5m付近 |
| 神通足：頂点（21f）で使用 | 8.29m | 7.91m | 5.5〜6.5mに余裕1.8m |
| 神通足：最良（落下中33f） | 9.05m | 8.60m | — |
| 神通足最良＋コヨーテ | 9.70m | 9.2m | 越えさせたくない隙間は10m以上 |
| 白雪の宙返り | 跳躍の頂点2.4m＋1.0m＝足が最高3.4m | — | 高さ2.5〜3.5mの乗れる面は置かない（6章の制約） |
- 段差：必須1.8m。最低の跳躍1.96mでも足が1.8m以上にいる区間は水平1.1m（走り）あり、登れる。
- **05への制約**（到達の規則の運用）：必須の隙間≤2.5m・段差≤1.8m／神通足前提の隙間5.5〜6.5m／越えさせない隙間≥10m／越えさせない壁の高さ≥3.6m。
- **03への制約**：1回の滞空で、技の `motion` による水平移動の合計は1.0m以下（神通足攻撃は、その滞空の神通足の移動と合わせて4.5m以下）。
- `runSpeedMul` の上限は1.12（走り跳び＋コヨーテ 5.10m < 5.5m）。`data/validate` で検査する。

## 4. 神通足・宙返り・ステップ

### 4.1 方向の決め方
| 動作 | スティック入力あり | 中立 | 注目中 | 体の向き |
|---|---|---|---|---|
| step | カメラ基準の入力方向 | 体の向きの真後ろ（後退） | 入力方向（注目中のカメラ基準）。中立は標的から離れる向き | 注目なし＋入力：進む向きへ即時に向く。中立：変えない。注目中：標的を向いたまま |
| airDash | 入力方向 | 体の向き | 入力方向。中立は標的の方向 | 進む向きへ即時に向く |
| flip | 使わない | 体の向きの真後ろ | 標的から離れる向き | 進む向きの逆（標的・元の向きを向いたまま後ろへ回る） |
- 宙返りがスティックを使わない理由：前方へ回れると跳躍の到達が5.5mを超え、白雪の欠け（神通足なし）が消える。

### 4.2 値と挙動
| 項目 | step | airDash（神通足） | flip（白雪の宙返り） |
|---|---|---|---|
| 全体 | 24f | 12f | 24f（空中の弧） |
| 移動 | 4.0m、1〜16fで `d(f)=4·(1−(1−f/16)²)`、17f以降0 | 4.5m、等速22.5m/s、`vy=0`（重力無視） | 後方2.5m（6.25m/s）、上へ1.0m（初速10m/s・専用重力50m/s²で12f目が頂点） |
| 無敵 | 2〜14f | 2〜9f | 1〜16f |
| 取消 | 18fから全行動・移動 | 6fから攻撃（神通足攻撃、03） | 18fから攻撃（空中射撃） |
| 終了後 | 接地の状態へ | jumpFall、`vy=0`、水平速度＝向き×走りの速さ（係数込み） | jumpFall、水平速度0（空中制御で再加速） |
| 回数 | 制限なし | 1滞空1回 | 1滞空1回 |
| 壁 | mover で滑る。無敵は続く | 1tickの実移動が予定の50%未満 → 即終了して jumpFall（水平速度0） | 同じ規則で後方移動だけ0にし、縦の弧は続ける |
| 崖 | 縁で止まる（2.3） | 空中なので関係なし | 同左 |
| 着地 | — | 途中で着地しない（重力なし） | 弧の途中で接地したら land |
- 開始の tick に `dodge {kind}` を出し、開始位置を見切りの残像として03へ渡す（判定は03）。
- 被弾：無敵外なら即 hitstun/launch。神通足中の被弾後も `airEvadeUsed` は真のまま。
- 白雪が空中で回避 → 常に flip。楓真・岩丈 → airDash。どちらの能力も無いキャラ（将来）→ 何もしない（ボタンは灰、01）。

## 5. 海への落下と復帰（`sim/stageLogic/sea.js`）
1. 安全地点：実tickで30tickごと（`safePointEveryF`）、接地・状態が idle/walk/run/land・地形の上（小道具の上は除く）・`edgeDist ≥ 1.5m`（`safeEdgeDistM`）・有効な穢域の外、をすべて満たせば位置と向きを8個の環状記録に入れる。
2. 落下を検出（09 6.3）→ fallSea。`seaFall` を出す。無敵・標的にならない（注目は解除、ソフトロック対象外）。攻撃権は04の規則で返す。
3. 36f：沈む見た目。カメラは追従を止め、落ちた点を見る（`camera.mode='sea'`）。
4. 18f：墨のワイプ（07）。
5. 復帰先＝最新の安全地点。ただしその3m以内に生存する敵がいれば、条件を満たす次に新しい点（全て駄目なら最新）。
6. 位置・向きを置き、速度0、`airEvadeUsed=false`。HP −round(最大HP×8%)、ただし1未満にはならない（海では死なない）。`respawn {reason:'sea'}`、補間を切る。カメラを背後へ即時配置（操作できない区間なので切替を許す）。
7. respawn 20f の後、操作を戻し、そこから局所60fの無敵。
- 落下の最中にHPが0になる攻撃は無い（fallSea は無敵）。ボス舞台の外周も同じ規則（安全地点は舞台の上に記録される）。

## 6. カメラ（`sim/camera.js`、実tickで更新）

### 6.1 モードと優先
`event`（05/04）＞ `sea` ＞ `boss`（04）＞ `lock`（8章）＞ `combat` ＞ `explore`。`GameStateView.camera.mode` に出す。
- combat への入り：生存する敵のどれかが水平10m以内、またはプレイヤーが被弾した。出る：水平14m以内の敵がいない状態が実時間で2.0s続く。`combatMode {on}` を出す。
- boss：`bossIntro` で入り、`bossDefeat` の後の04の演出終了で explore。死亡・海から舞台上へ復帰したら boss のまま。boss 中も注目の状態機械（8章）は動き、カメラの姿勢は04が計算する。切替の補間1.0s。
- 距離・注視点の高さ・肩オフセット・既定の縦角は、モードの値へ τ0.25s の指数平滑で移る（`x += (目標−x)·(1−e^(−dt/τ))`）。FOVはモードで変えない。

### 6.2 姿勢
```
pivot = 平滑後の足元位置 + (0, pivotHeight, 0) + right(yaw)·shoulder
pos   = pivot − forward(yaw, pitch)·dist     （pitch は上から見下ろす向きが＋）
注視方向 = pos → pivot
```
| モード | dist | pivotHeight | shoulder | 既定の縦角 |
|---|---|---|---|---|
| explore | 5.0m | 1.5m | 右0.35m | 14° |
| combat | 7.0m | 1.5m | 0 | 20° |
| lock | 7.0〜10m（8.2） | 1.5m | 0 | 15° |
- 水平の追従：pivot の XZ を τ0.10s で平滑。
- 縦の追従：基準高さ `baseY` は接地中の足の高さ（τ0.25sで平滑）。空中では baseY を据え置く。ただし ①足が baseY−1.0m より下へ落ちた ②滞空が0.5sを超えた、のどちらかで足の高さへ τ0.30s で追う。跳躍1回でカメラが上下しない。
- 手動：`camDeg[0]` を yaw に、`camDeg[1]` を pitch に足す（上下反転は入力層）。pitch は −30〜+60°。px→度の基準感度は本書の `camYawDegPerPx`=0.30・`camPitchDegPerPx`=0.18 で、入力層（`input/collector.js`）が `camSensPct` と攻撃ドラッグ0.8倍とともに掛けて `camDeg` を作る。
- 縦角の自動復帰：カメラ入力が2.5s無く、移動中または combat のとき、既定の縦角へ15°/sで戻す。

### 6.3 自動回り込み（explore・combat のみ）
- 抑止タイマー：カメラの手動入力（`camDeg≠0` または `camHeld`）のたびに1.8s。注目の解除・combat の終了・復帰・boss からの復帰・背後リセットの終了のたびに1.2s（大きい方を残す）。起動時1.2s。
- 条件：抑止タイマー0、接地または空中で移動入力あり（m≥0.15）、`|stick.x| ≥ 0.10`、移動方向とカメラ前方の差が120°以下（カメラへ向かって走るときは回らない）。
- 回す量：yaw を「キャラの背後（移動方向）」へ `75°/s × |stick.x| × 強さ`。強さは設定 `camAutoTurn`：off 0／weak 0.5／normal 1.0。残り角を超えない。
- 注目ボタンで敵がいないとき（背後リセット）：yaw を体の向きへ、pitch を既定へ 0.25s で線形補間。途中の手動入力で中断。`camReset` を出す。

### 6.4 障害物
1. 09 6.6 の球の刻み判定（半径0.25m・刻み0.25m、`config/collision.js`）で pivot から希望位置までの当たり距離 `h` を得る。半径0.4m未満の円柱（千本鳥居の柱）、敵、ボス、`camBlock=false` の形状は対象外。
2. 実際の距離 `cur`：`h < cur` なら τ0.05s で寄る、そうでなければ τ0.40s で戻る。下限0.8m。
3. 地面：カメラ位置の `heightAt + 0.3m` より下なら上げる。
4. 透かし：pivot→カメラの線分から0.6m以内にある対象外の物（細い柱・敵・ボス・小道具）のIDを `camera.fadeIds` に入れる（描画が網点で透かす、07）。`cur < 1.2m` ならプレイヤー自身も透かす。

### 6.5 視野角
```
a  = viewPx[0] / viewPx[1]
v  = 55 + camFovOffsetDeg（設定 −5〜+5）
hx = 2·atan(tan(v/2)·a)
hx > 100° → v = 2·atan(tan(50°)/a)、 hx < 90° → v = 2·atan(tan(45°)/a)
v = clamp(v, 45, 65)
```
- 844×390（a=2.16）→ v=55°、横96.8°。16:9 → v=58.6°。20:9（2.22）→ 55°（横98.5°）。4:3 → 65°（横81°、上限で止まる）。
- 値の変化（回転・ツールバーの出入り）は0.3sで補間。

### 6.6 ヒットストップ・揺れ
- カメラは実tickで動き続ける。ヒットストップで止まるのはキャラだけで、カメラの寄り・FOV変化は起こさない。
- 画面揺れの**量**（trauma の加算・減衰・最大値・雑音、設定 `shakePct` の掛け方）は 03 5.4 が正本で、描画側 `render/feel/shake.js` の純関数がイベントから計算する（キーは `config/combat.js`）。本書は持たない。
- 本書の担当は**適用だけ**：`render/cameraView.js` が、シムのカメラ（位置・向き）を補間した後に、shake.js の返すロール角と平行移動（カメラ局所の右・上方向）を描画用カメラにだけ足す。シムのカメラ（画面内判定・タップ・矢印・ハッシュに使う）は揺らさない。FOV と障害物よけには影響させない。

## 7. ソフトロック（`sim/lockon.js`）

### 7.1 候補と点数
- 候補：生存する敵（`lockable`）。半径 R（キャラの `softLockRangeM`：楓真・岩丈8m、白雪20m）以内の3D距離、見上げ・見下ろし60°以内、胸の高さどうしの視線が地形・`projBlock` 形状で遮られない。
- 敵の候補が無いときに限り、穢石と穢核も同じ条件で候補にする（白雪が高所の穢石を狙える）。
- 基準方向 `dRef`：スティック入力あり（m≥0.15）ならその方向、中立なら体の向き。`dRef` から±60°の外は除く。
- 点数：`4·(1 − aRef/60°) + 2·max(0, 1 − aCam/90°) + 1·(1 − dist/R)`（aRef＝dRef との角度、aCam＝カメラ前方との角度）。直前1.0s以内に同じキャラの攻撃が当てた標的には +0.5（連撃中の乗り換え防止）。最大を選ぶ。
- 近接の救済：スティック中立で候補0、かつ2.0m以内に敵がいれば、最も近い敵を選ぶ（背後に張り付かれたとき）。
- 注目中：注目の標的が R 以内ならそれを使う。R の外なら向き直りだけ行い、踏み込まない。

### 7.2 向き直りと踏み込み
- 向き直り：行動の開始tickに体の向きを標的へ即時に合わせる。標的なしならスティック方向（中立なら今の向き）。
- 踏み込み（地上の攻撃のみ）：`gap = 水平距離 − 自分の半径 − 標的の半径`。`gap > 0.6m` なら `min(gap−0.6, lungeMaxM)` を技の `startupF` に均等に配って前へ進む（`motion` に足す、1tick上限30m/s相当＝3.5m を7fで配れる速さ）。`lungeMaxM`：楓真3.5m・岩丈3.5m・白雪0。崖の縁と壁で止まる。空中の攻撃は踏み込みなし。

### 7.3 使う行動
| 行動 | 評価の時点 | 半径 | 向き直り | 踏み込み |
|---|---|---|---|---|
| 攻撃（連撃の各段・空中攻撃） | 各段の開始tick | softLockRangeM | あり | 地上のみ |
| 神通足攻撃 | 開始tick | softLockRangeM | あり | なし |
| 白雪の射撃 | 各射の開始tick。射撃中は標的へ向きを固定 | 20m | あり | なし |
| 結界 | 押下が受理されたtick | `kekkaiRangeM`（楓真・岩丈5m、白雪15m） | あり | なし（標的なしは前方へ罠、03） |
| 奥義 | 離して発動するtick | softLockRangeM | あり | なし（技の motion は03） |
| 符：一穴 | 発動tick | `fuIkketsuLockM` 20m | 矢の向き | なし |
| 符：滅・浄・守・醒、ステップ | 使わない | — | — | — |

## 8. 注目（ハードロック）

### 8.1 開始と解除
- 開始：①注目ボタン、②`taps` の位置が、敵の外接球を画面へ投影した円＋20px 以内（重なれば最もカメラに近い敵）。`lockOn {targetId}` を出す。
- ボタンでの選び方：候補＝`lockable`・生存・30m以内・視錐台の内側・カメラから視線が通る。設定 `lockPriority`：`nearest`（既定）＝最短距離、`center`＝画面中心からの角度が最小、`lowHp`＝HP割合が最小（同点は距離）。候補0なら、画面外も含めて30m以内の最も近い敵。それも無ければ背後リセット（6.3）。
- 注目中にボタン → 解除。
- 自動解除：標的の撃破（次へ自動では移らない。理由：意図しない視点移動を避け、群れはソフトロックが受け持つ）、水平距離30m超、「見えない」状態が実時間で1.2s続く（視錐台の外、またはカメラから標的中心への線が地形・camBlock 形状で遮られる、または `lockable=false`）、プレイヤーの fallSea・respawn・dead・event。解除で `lockOn {targetId:null}`、自動回り込みの抑止1.2s。

### 8.2 カメラ（mode=lock）
- 注視点 `pivot = lerp(自分の胸（足+1.5m）, 標的の中心, 0.38)`。
- yaw の目標＝自分→標的の水平方向＋ずらし角。τ0.12s、最大360°/sで追う。水平距離1.5m未満では yaw を据え置く（真上で回り続けないため）。
- 距離 `7.0 + 0.15×max(0, 標的までの距離 − 6)`、上限10m。縦角は手動で動かせる。既定15°。
- 自分の画面位置：標的が8m・同じ高さのとき、自分の中心は画面の横0.45〜0.55、縦（上から）0.55〜0.72に入る（受け入れ基準）。

### 8.3 はじきでの標的切替
- `frame.flick = ±1`（判定は入力層：180ms以内・横40px以上・横が縦の2倍以上・1回のドラッグで1回、01 2.5）。シムは冷却0.25s（実tick）の間の flick を捨てる。
- 候補：開始時と同じ条件（30m・視線）で、カメラ前方から±120°以内。各敵の符号付き角 `a`（カメラ前方からの水平角、右+）。右（+1）なら `a > a現在 + 2°` のうち最小の `a`、左なら最大の `a`。無ければ切り替えない（端で止まる、回り込みはしない）。
- 切り替えたら、ずらし角を0にする。

### 8.4 ゆっくりした横ドラッグ（注視ずらし）
- 注目中、`camDeg[0]` は yaw ではなく「ずらし角」に足し、±35°で止める。`camDeg[1]` は常に縦角。
- `camHeld=false` になったら、その時点の値から0.5sで線形に0へ戻す。

### 8.5 注目中の移動（決定：敵中心の周回）
- スティックはカメラ基準（＝標的基準：上＝標的へ、横＝回り込み）。
- 標的との水平距離が1.5〜15mのとき、移動を「半径方向」と「接線方向」に分け、接線成分は標的中心の円周に沿って動かす（移動後に、距離＝元の距離＋半径方向の移動量 となるよう位置を標的中心から投影し直す）。範囲外は通常のカメラ基準移動。
- 体の向き：歩きでは標的を向いたまま（横歩き・後退）。走りでは進む向きを向く。
- 理由：横に回るたびに標的から離れていくと、近接は間合いを、白雪は射程を管理しにくい。

## 受け入れ基準（自動テスト）
1. 平地で走り入力（stick=[0,1]）を1.0s → 水平速度6.5±0.05m/s、0.12sの時点で6.5±0.3。
2. 走り中に中立 → 0.08s±1tick で速度0。
3. stick 長さ0.54 → 速度2.5±0.05、0.56 → 6.5±0.05。走り中に0.52 → 走りのまま、0.49 → 歩き。
4. 岩丈で走り1.0s → 5.85±0.05m/s。
5. 跳躍を押し続け → 頂点の足の高さ2.40±0.02m、頂点まで21±1tick、平地への着地まで36±1tick。
6. 跳躍を1tickだけ押す → 頂点1.96±0.03m。
7. 走り跳び（平地） → 離陸点〜着地点の水平距離3.90±0.05m。

## 依頼者が実機で確かめること
1. 歩きと走りの切り替わりが自然か。親指を少し倒すと歩き、大きく倒すと走るか。
2. 跳躍のふわっと感と落ちる速さが心地よいか。崖を神通足で越えるのが「狙えば届く」くらいか。
3. 歩いて崖際に寄ったとき落ちず、走ると落ちることに違和感がないか。
4. 走っているとカメラがゆっくり背後に回るが、自分で回した直後は邪魔しないか。千本鳥居の中でカメラが寄ったり戻ったりちらつかないか。
5. 注目中に、はじきで標的を切り替えられ、ゆっくり横になでると少しだけ見回せるか。
6. 画面が揺れて酔わないか（揺れ・回り込みの設定を下げたら楽になるか）。
