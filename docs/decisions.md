## 第1回 設計協議（r1：ゲームデザイン・スマホUX・実装・美術音響の4レビュー）

### 依頼者の決定（変更には依頼者の承認が必要）
- U1 スマホブラウザ・横画面・タッチ操作。Three.js。
- U2 キャラはステージ前に1人選ぶ（原作どおり）。試作3人、将来5人。
- U3 封陣符は五芒星を指でなぞる。
- U4 見た目はコードで表現できる範囲の最上位を目指す。
- U5 試作は物語を作り込まず、操作性の確認を重視。細かい仕様は設計側に一任。

### 基本方針
- D1 **一つの操作には一つの意味**。例外：回避ボタンは空中で神通足（白雪は宙返り）。理由：原作の不満（奥義の暴発、封陣符の数え違い、ボス限定ロック）はすべて操作の多義性が原因。影響：全操作。
- D2 **奥義は専用ボタンの長押し**、攻撃ボタンは長押しの意味を持たない。理由：同上。
- D3 **相克倍率 与×1.5／被×0.75**（原作×2/×0.5）。倍率の積の上限×3.0。理由：1人選択制で選択ミスが致命的にならないため、結界・醒との重なり防止（r1-GD M5）。影響：敵HP、撃破時間。
- D4 **時計は2つ**（実tickと局所時間）、時間倍率は掛け算（r1-ENG A1）。理由：ヒットストップ・見切り減速・符の構えが重なっても破綻しない。影響：全タイマー。M0で固定。
- D5 **カメラはシミュレーション側**（r1-ENG A3）。理由：カメラ基準の移動・ソフトロック・画面内判定が結果に影響し、テストの再現性に必要。
- D6 **見切りは「回避開始位置に残す残像の被弾判定」で判定**（r1-ENG A2）。受付10f（易しい14f）、入力はイベントのtimeStampで補正（r1-UX B5）。
- D7 **ダメージ種別 打・射・術**（r1-GD M7）。穢石・穢核は打・射・一穴でのみ壊れる。
- D8 **キャラは剛体スキンの1メッシュ＋輪郭1**（r1-ART 必須4、r1-ENG A5）。攻撃判定は骨に依存しない。
- D9 **衝突は高さ格子＋円柱/箱/球の解析形状**、物理エンジンなし（r1-ENG A4）。敵の移動は「歩ける1m格子」の距離地図（r1-ENG B2）。
- D10 **入力層は全画面1枚**、ボタン判定は配置設定の数値で行い、DOMのHUDは見た目専用（r1-ENG A6）。

### ゲームデザイン
- D11 **導入（チュートリアル）を浜の参道に組み込む**。使えないボタンは隠し、1つずつ解放（r1-GD M1、r1-UX B7）。2回目以降は省略可。
- D12 **ボス前から再挑戦**できる（鳥居で記録）（r1-GD M2）。→ D57 で「記録地点から」に一般化。
- D13 **相性は3軸（ボス／道中／探索）で表示**（r1-GD M3）。敵の属性を変更：穢狗=水、唐笠=木、灯魂=金、面鬼=土、ボス=土。
- D14 **白雪は射程・結界距離・ソフトロックを別値**（20m/15m/踏み込みなし）、矢で穢石を壊せる（×0.5）、近接技なし（蹴りは削除：距離で技が変わる＝D1違反）、空中回避は宙返り（r1-GD M4、r1-ENG A7）。
- D15 **醒は15秒・攻×1.3・被×0.7、札消費なしは削除**（r1-GD M5）。
- D16 **ボスへの封破は×1.5、封印解除後10秒は再封印不可**（r1-GD M5）。
- D17 **穢域の中心に穢核**（打・射・一穴で破壊、札+2）。感染は12秒で自然治癒、感染中の札回復は半分（r1-GD M6）。
- D18 **ボスに技を2つ追加**（地走り・四股）、第1段階は固定順、第2段階は要石2つ（原作の結晶の継承）が崩しの蓄積を半減（r1-GD M8）。撃破目標2.5〜3.5分。
- D19 **跳躍到達の規則**：必須経路は水平2.5m・段差1.8m以下、神通足前提の経路は5.5〜6.5m、強化で開く場所は作らない（r1-GD M9）。神通足の無い白雪のため、高所の穢石には地上からの射線を必ず作る。
- D20 **見切りの報酬**：敵×0.3を1.5秒、その間は結界の消費なし、札+1（2秒に1回まで）（r1-GD R1）。
- D21 敵は固定配置・再出現なし（小型約20・大型2）。敵が作った穢域の浄化はゲージ+2（r1-GD R4）。
- D22 岩丈の怯まないのは2・3段目の攻撃中のみ（r1-GD R5）。
- D23 龍穴の回復は1回の滞在で最大HPの40%まで、使い切ると60秒で再使用可（r1-GD R9）。
- D24 札の属性連鎖は削除。相生は龍穴でのみ使う（r1-GD R10）。
- D25 地脈ゲージ100の報酬は「ボス戦の被ダメ×0.85・結界+1」と演出（全回復ではない）（r1-GD M2）。
- D26 魂片は全キャラ共通の財布、強化はキャラ別。穢石の魂片は初回のみ満額、以降は1。拾った時点で保存（r1-ENG A7-8）。
- D27 敵の攻撃で海へ落とされない（崖際のノックバックを制限）（r1-GD R8）。

### 操作・UI
- D28 **画面配置は r1-UX の最終レイアウト**（右下の角からの距離で配置、safe-area内）。回避を大きく（68/84）、ロックは「注目」ボタンとして跳躍の上へ（r1-UX A1〜A3）。
- D29 **五芒星**：中心は右下から(200,164)、半径84px固定。今いる点から捕まえられるのは相剋の線でつながる2点のみ。吸着あり。最初の接触まで1.5秒・描画3.0秒・離しても0.25秒は継続・5画で即発動（r1-UX A4）。初回の既定は「補助」モード。
- D30 **奥義の溜め中に回避ボタンへ滑らせると取消して回避**、取消は押下点から72px（r1-UX A5）。溜めは実tickで数える。被弾で取消（消費なし）。
- D31 **ハードロック中の標的切替は「はじき」のみ**、ゆっくりした横ドラッグは注視方向を±35°ずらす（r1-UX A6）。
- D32 **攻撃ボタンを押したまま28px以上動かすとカメラ操作**（右親指の空き領域が遠いため）（r1-UX B2）。
- D33 残数（札・勾玉・結界）はボタン上に表示、画面外の予兆は自キャラの周り半径90pxの円上に表示（r1-UX B1）。
- D34 ブラウザ対策（戻る・長押し・ズーム・縦向き・音の中断・保存の消失）は r1-UX A7 を採用。タイトルは「音を出して遊ぶ／音なしで遊ぶ」。
- D35 縦の視野角は55°を既定とし、横の視野角が90〜100°に収まるよう縦横比で調整（r1-UX B4）。

### 美術・音
- D36 **墨絵セル＋紙墨パス（1パスの後処理）**。紙の粒・色調・周辺減光・ディザを1つに統合。高品質のみ深度による背景の輪郭（r1-ART 推奨1）。
- D37 **明度の三層**（背景は明・体は暗・危険は暗い芯＋明るい縁）を最上位の規則にし、白黒スクリーンショットで検査（r1-ART 必須5）。
- D38 **加算合成は暗い面の上と1〜3fの閃光のみ**（r1-ART 必須1）。
- D39 **色の役割**：最高彩度の朱#e2452bはゲーム情報専用、環境の朱は#a3412e、穢れは暗紫#2a1730＋朱紫#b0306a、属性色は r1-ART 必須2 の表（r1-ART 必須2・3）。
- D40 **霜月の夕刻に固定**、ボス舞台の真後ろに巨大な朱の夕日（方位の目印）（r1-ART 推奨3）。
- D41 穢域・龍穴・丸影は地形シェーダーの円の配列で描く（半透明の重ね塗りを避ける）（r1-ENG B1）。
- D42 音は合成のみ。iOSの消音スイッチ対策を M0 で入れ、実機確認を依頼者の確認項目にする（r1-ART 必須7）。→ D48 で BGM のみ音声ファイルに改定（効果音・環境音は合成のまま、消音スイッチ対策は継続）。

## 第2回 統合（11/13〜14：各詳細設計書の食い違いの調停。core v0.3）

### 依頼者の決定
- U6 BGMは依頼者が Gemini（Lyria 3 Pro）で生成した音声ファイルを使う。効果音・環境音はコード合成のまま。

### 決定
- D48 **BGM は音声ファイル**（U6）。`public/audio/bgm/<曲ID>.m4a`（AAC、無ければ `.mp3`）、読み込みはタイトルのタップ後、ループは終端と先頭を重ねてぼかす、曲間でテンポと調をそろえる。ファイルが無い間は無音（または合成の仮BGM）で動く。理由：依頼者の決定。合成の BGM は品質の上限が低い。依存ではなく静的ファイルなので不変条件11（依存4つ）は維持し、例外は BGM のみ（変換前の素材は公開しない `assets-raw/`）。影響：core 11・12、08 5〜7章、09 1.1・1.4・2章、D42。
- D49 **InputFrame は 09 に一本化**。`camDeg`（度。px→度は入力層が02の基準感度×設定で換算）、`ougiOut`（取消域の間は真＋滑らせ・静かな解放の1tick）、`fu{touching, first, edges, commit, cancel}`、`camHeld` を加える。01 の `camPx`・`ougiCancel`・`fu.start/newEdges` は不採用。理由：シムが px と画面の大きさに依存すると端末で挙動が変わり、リプレイが壊れる。取消を「状態」で持つと複数tick進む描画でも取りこぼさない。名前の正本を1つにして実装AIの推測をなくす。同じ描画区間の短いタップは「1tick目 down・2tick目 released」（09）。影響：01 2章・9章、02 0章、03 8・9章、09 3・5章。
- D50 **画面揺れの量は03 5.4（描画側の純関数 `render/feel/shake.js`）が正本、02 は適用のみ**（描画用カメラに足す。シムのカメラは揺らさない）。02 の揺れの値とキーは削除。理由：手応えの調整を1か所で行う。軽い命中では揺らさない（酔い対策）。影響：02 6.6・9.2、03 5.4、07 8.2、09 1.4。
- D51 **入力の優先は 回避＞奥義＞結界＞符＞攻撃＞跳躍**。窓が開いた最初のtickに保持中の1つだけを実行し、残りは捨てる（03 C2）。理由：連打の取りこぼしと二重発動をなくす。影響：core 7.2、02 0章、03 2.4。
- D52 **時間倍率は1/4096で量子化、変化は次のtickから**（03 C1）。導入中の世界倍率（0〜1、台本が指定）を時間の規則に入れる（01 提案1）。理由：倍率の和を端末間で誤差なく足す。導入の「ゆっくり」「止める」を時間の規則の内側で実現する。影響：core 4章、03 1章、05 の導入台本。
- D53 **ボスの「封」は見切り不可・回避の無敵を貫く（`ignoreInvuln`）。見切られた攻撃は以後当たらない。見切り中は結界の所持0でも張れる**（03 C3・C4）。理由：封は「範囲から出て避ける」技として予兆の意味を一つにする。見切りの報酬を確実にする。影響：core 7.3、03 6章、04（封の技データ）。
- D54 **封破は、封印を割った奥義のその敵への全命中に×2.0（大型・ボス×1.5）。余波は連鎖しない**（03 C5）。理由：多段の奥義でも封破の相性が死なないため。連鎖は群れを一掃しすぎる。影響：core 7.4、03 7.4・4.6。
- D55 **奥義の溜めと符の構えは地上のみ**。空中の奥義の押下は着地から溜め、接地を失ったら取消（`ougiCancel.reason='air'`）。符の構え中の被弾は取消（消費なし・1sの再構え禁止）。描き始める前に限りスティック範囲のタップで手動取消（01 提案3）。理由：落下中の扱いを無くし、技が地上の型であることと揃える。構え中は全ボタンが隠れるため取消手段が要る。影響：core 7.4、01 3.5、03 8・9章。
- D56 **攻撃側のヒットストップは1技の合計に上限（14／20）、撃破の一撃は+3f（上限20）**（03 C7）。理由：多段技で攻撃側が凍り続けるのを防ぎ、撃破の手応えを足す。影響：core 7.2、03 5.1。
- D57 **再挑戦は「記録地点から」**（05のチェックポイントと鳥居。鳥居の後は「ボス前から」と表示）。どの記録地点でも勾玉は最低3。魂片：ボス撃破 初回10・以降3、小型10%で1、大型2。同じ run で戻った場合、穢石の魂片と敵の落とし物は二重に払わない（06）。理由：区画の途中で死んでも長く戻されない。死に戻りで稼げないようにする。影響：core 3章、01 5.6・5.8、03 8.1、06 5・8章、09 `RetryV1`、05 のチェックポイント。
- D58 **結界の最大は3、強化で5、地脈100のボス戦で6**（06）。理由：D25 の+1と強化の上限の関係を確定させる。影響：core 7.4、03 7.2、06 4章。
- D59 **移動の追加値**（02）：早離しは最低12f保持（最低の高さ1.96m）、手動カメラ操作直後の自動回り込み停止は1.8s、越えてはならない隙間10m以上・登れてはならない壁3.6m以上、神通足前の空中の水平到達は最後の接地点から4.8mで頭打ち、神通足の無敵2〜9f、奥義の溜め中の最高速＝走り×0.4（楓真・白雪2.6m/s、岩丈2.34m/s。キーは02の `ougiChargeMoveMul`）。空中技の水平移動は1滞空1.0m以下、神通足攻撃は神通足と合わせて4.5m以下（03 2.4 で打ち切る）。理由：タップでも必須の段差に届く。到達の規則を宙返り・空中技で破らない。影響：core 6章・7.4、02 3〜4章、03 2.4、05（地形の寸法）。
- D60 **プレイヤーの被弾の無敵は03 11.1 が正本**：ダウン24f（無敵）→起き上がり45f無敵、15fから行動可、攻撃・奥義・結界・符を始めたら無敵を打ち切る（移動・回避・跳躍では続く）。02 の値（30f／30fから取消）を合わせ、キーは03の `plDownF/plGetupInvulnF/plGetupLockF` のみ。被弾カプセル・kekkaiRangeM（楓真・岩丈8m）も03の値に06を合わせる。理由：同じ値の二重定義をなくす。影響：02 1.1・9.1、06 1.2。
- D61 **決定論は同一JSエンジン内で保証、実機の記録は近似再現**（09 P4）。`src/gen` もシム側に含める（P3）。単位接尾辞に `Mps2 Hz Db Bpm Count` を足す（P2・08 提案3）。`config/audio.js` の `sfxRecipes` は接尾辞検査の対象外。理由：`Math.sin` の最後の桁はエンジンで違い得る。生成関数はシムと描画が共用する。音とテンポに当てはまる接尾辞が無い。影響：core 0・12章、09 2章。
- D62 **イベント名は 09 3.1 に統一**（07 の `kekkaiCast`→`kekkaiPlace`、`ougiChargeStart/Level`→`ougiCharge{stage}`、`enemyDeath`→`kill`、`chimyakuStage`→`gaugeStage`、`eikakuBreak`→`ekakuBreak`、`ryuketsuDepleted`→`ryuketsuDeplete`、`bossMove`→`telegraph`/`swing` の moveId、`bossPhase2`→`bossPhase`）。09 に `esekiHit`・`hitRevoked`・`kekkaiFail`・`telegraph.moveId`・`ougiCancel.reason 'air'`・`buff.kind 'mamori'`・`respawn.reason 'restart'/'retryCheckpoint'` を追加。低HPはイベントにせず描画・音が `hp/hpMax` で判断（<25%開始・≥28%停止）。低HPの表現は `uInk`（`uLowHp` は廃止）。hit の強さの段は heavy または hitstopF≥12＝重、8〜11＝中。理由：同じ出来事に複数の名前があると購読漏れが起きる。影響：01 4.3、07 3.7・8.2、08 8章、09 3.1。
