## 1. 座標系・寸法・地形

### 1.1 座標系
- **+X＝東、+Z＝南、+Y＝上**（右手系、07 3.3「+X東・−Z北」と一致）。原点は地図の**北西の角**の海面高さ。地図は X 0〜140m、Z 0〜110m。
  - 09 v1.2 の StageDef も「原点＝北西の角」に訂正済み（S0）。
- 向き `yawDeg`：03 2.2 の `F=(sin yaw, 0, cos yaw)`。0°＝南、90°＝東、180°＝北、270°＝西。
- 方位（07・01の方位帯）：北から時計回り。**水平ベクトル (dx,dz) の方位 = atan2(dx, −dz)**（北0°・東90°・南180°・西270°）。
- 海面 `seaLevelM` 0。海底 `seaFloorM` −4。高さ格子は0.5m（頂点281×221、09 6.1）、歩ける格子は1m（09 7章）。

### 1.3 高さの式（`gen/terrain.js` の `shirasagiTerrain(params, seed)`。シムと描画が共用）
```
① 台地の合成   h0(x,z) = max( seaFloorM, max_i P_i(x,z) )
   P_i = H_i + (seaFloorM − H_i) · smoothstep(R_i, R_i + W_i, d_i)
   d_i = 円：中心からの水平距離 ／ 線分：線分までの水平距離
② 起伏        h1 = h0 + fbmAmpM · fbm(x,z) · mask(x,z)
   fbm = valueNoise2 の4オクターブ（基本周波数 1/16 m⁻¹、周波数×2、振幅×0.5）を [−1,1] に正規化。
         種 = hash32(seed, 'terrain')（09 core/hash・core/noise）
   mask = smoothstep(1.0, 3.0, h0) × Π_k smoothstep(r_k, r_k + 2.0, |p − c_k|)   （平らに保つ円 k、表1.5）
③ 道の上書き（R1→R4 の順）  dist＝折れ線までの距離、s＝折れ線上の弧長、L＝全長
   hp = h_start + (h_end − h_start)·s/L
   h  = hp + (h − hp) · smoothstep(width/2, width/2 + shoulder, dist)
④ 平場の上書き（L1, L2）    h = hl + (h − hl) · smoothstep(r, r + 1.0, |p − c|)
```
`smoothstep(a,b,x)`＝t²(3−2t)、t=clamp((x−a)/(b−a),0,1)。高さ格子の各頂点でこの式を評価する（描画の頂点も同じ値、09 2章-6）。
